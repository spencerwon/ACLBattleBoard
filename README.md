# ACL Battle Board

Rate, rank and plan the Austin City Limits 2026 Weekend Two lineup. Swipe-rate each act, settle ties head to head, and get a Hot/Warm/Cool/Cold schedule for each day. Ratings save in your own browser. Each board also sends its name, ranking code and a random browser ID to the host's private stats page (`/stats.html`, key required); no IP addresses or other personal data are stored. Deploy previews and local copies send nothing.

Live at https://acl2026battleboard.netlify.app/
